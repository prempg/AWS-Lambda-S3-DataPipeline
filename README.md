# AWS-Lambda-S3-DataPipeline

# AWS Serverless Data Pipeline (Lambda + S3)

An automated event-driven ETL data pipeline designed to ingest raw sales records, clean invalid data points, calculate key business metrics, and write aggregated reports to cloud storage.

---

## Architecture Overview
- **Storage Layer (Amazon S3)**: Hosts raw CSV transactional data in `/input` and receives transformed summaries in `/output`.
- **Compute Layer (AWS Lambda)**: A serverless Python execution environment configured to process S3 stream buffers and execute aggregations without provisioning servers.
- **IAM Security**: Configured with least-privilege policies granting read and write access to the targeted S3 bucket.

---

## Pipeline Execution Logic
1. **Extraction**: Reads `sales_data.csv` directly from the S3 bucket input prefix.
2. **Transformation**:
   - Strips whitespace and normalizes column headers.
   - Cleans null values across sales and profit fields.
   - Groups records by `Category` and `Region`.
   - Aggregates `Total_Sales`, `Total_Profit`, and `Total_Orders`.
3. **Loading**: Serializes aggregated data to CSV format and dumps `sales_summary.csv` into the bucket's output folder.

---

## File Structure
- `lambda_function.py`: Core transformation and S3 handler script.
- `sales_data.csv`: Sample transactional test dataset.
- `sales_summary.csv`: Aggregated output generated by the function.
